Les versions de moteurs, chiffres commerciaux, citations indirectes et affirmations de faisabilité qu'elles contiennent n'ont pas été vérifiés. Aucune version de moteur ni promesse de calendrier n'est retenue dans la documentation de travail.

Continuer les modifications dans les documents de travail et conserver ces sources comme archives.
